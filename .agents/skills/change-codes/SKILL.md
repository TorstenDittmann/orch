# change.codes

Use the change.codes MCP tools for repository context, Changes, reviews, checks, evidence, and landing.

- Read the current Change and repository context before acting.
- Keep work attached to a Change so intent, revisions, checks, and review stay together.
- Record test, benchmark, or screenshot evidence after verification.
- Never expose credentials in messages, commits, logs, or tool arguments.
- Ask before landing a Change unless the user explicitly requested it.
